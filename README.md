## 📌 About

This repository contains my work and programming practice completed as part of **Industry Oriented Training (IOT) — Phase 1**.

The training focused on strengthening core programming skills through **Java Fundamentals, Data Structures & Algorithms (DSA), and Java-based problem solving**.

The repository documents my learning through regular programming exercises, implementations, and problem-solving practice.
